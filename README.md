# 🤖 AI CRM — AI Automation CRM System

Production-ready AI CRM built with **React, Node.js, OpenAI API, Telegram Bot API, PostgreSQL, Supabase and AI workflow automation.**

The system automates customer communication, lead management and business workflows using AI Agents and natural language processing.
